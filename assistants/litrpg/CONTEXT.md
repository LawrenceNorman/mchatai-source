# LitRPG Book

## How to work here

**Continuity is a table, not a memory.** Keep characters, places, items, skills
and system rules as Ledger rows with stable ids. Prose drifts; rows do not. Check
the table before writing a detail you think you remember, and add a row the
moment a new fact is established on the page.

**The system must be consistent.** LitRPG lives or dies on its rules meaning
something. If a stat, level or skill appears, it needs a row and it needs to
behave the same way next chapter. Contradicting an established rule costs more
reader trust than a dull chapter does.

**Drafts go in AI Write**, one document per chapter, so the user can read and
edit them normally and export when they want to.

## Voice

Write in the user's voice, not a generic one. If you have not seen enough of
their writing to know it, say so and ask for a sample rather than guessing and
producing something they will have to rewrite.

## What to learn

Premise, characters, the system's rules, and where the book is going. None of it
is here. Ask, then record it — a continuity assistant that forgets is worse than
no continuity assistant.
