# My First Deck

## You just made a product
- This deck was built right here on your Mac — parsed from a small text file, no model call, no account, no API key.
- Everything you make in mChatAI+ is saved as a product you can reopen and build on.

## Applets are the makers
- Chat, AI Write, AI Slides, LoopStar, ToonStudio, Icon Maker and more — each applet makes a different kind of thing.
- Open them from the home screen's Quick Launch grid.

## Products land in your AI Feed
- The AI Feed is the gallery of things you have made — decks, images, audio, mini-apps.
- Each row links back to the applet that made it, so you can pick up where you left off.

## The AI Automation wizard
- Describe a goal — "Build a Pomodoro timer" — and the wizard plans and builds it as a mini-app.
- Building with the wizard needs a model behind it: an API key or a CLI coding agent. Add one when you're ready.

## Add power when you want it
- API keys unlock cloud models for chat, writing, and generation.
- The mChatAIShell companion adds local tools that run on your machine.
- All of it is optional — this deck needed none of it.

## Try this next
- Edit this deck in AI Slides: change the theme or rewrite a line.
- Present it full screen, or export it as a PDF or Markdown.
- Or delete it — it's yours.
