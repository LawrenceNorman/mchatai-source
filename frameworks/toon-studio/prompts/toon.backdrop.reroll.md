Your previous attempt drew only {{PATHS}} expanded paths, which will read as a few flat slabs.

Draw the SAME location again, and fix it by adding DISTINCT OBJECTS — not by repeating what you
already drew. A wall of 40 identical rectangles is not scenery; it is one rectangle forty times, and
it reads as a smear.

Ask yourself what a person would actually see standing there, and draw those things as separate
shapes: the thing the location is NAMED after, first and largest, then a doorway, a window, a roof
line, a fence, a tree, a path, a distant hill. Three or four recognisable objects beat four hundred
repeated ones.

Use `polygon` and `path` for anything with a slope, a point or a curve — a roof, a hill, a gable, a
bundle of sticks, a tree crown, a thatch edge. `rect` is for the ground, the sky bands and flat
walls, and a set built only from rects has already failed.

Keep `repeat` for genuine texture — bricks in a wall, planks in a fence, tiles on a roof — where the
repeated unit is SMALL relative to the object it fills. Never repeat something the size of the
object itself.
